# Audit SEO AUPOSITEUR — 15 septembre 2026

## Décisions conservatrices

- Le design validé n'est pas modifié.
- `https://www.aupositeur.be` reste provisoirement le canonical, car `astro.config.mjs` le définit déjà ainsi. Le choix www/non-www doit être aligné avec DNS/Cloudflare avant toute modification.
- L'ancienne boutique interne reste exclue de l'indexation : la navigation publique pointe désormais vers Fourthwall et les routes internes `/boutique/` sont redirigées vers l'accueil.
- Les anciennes URL Google Sites ne sont pas encore activées dans `_redirects`; une proposition séparée est fournie pour validation.

4. `public/_redirects-seo-proposal.txt`
   - documente les redirections 301 proposées depuis l'ancien Google Sites sans les activer prématurément.
